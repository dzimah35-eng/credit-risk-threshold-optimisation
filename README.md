# Data Dashboard Showcase

An interactive set of three dashboards that show how I turn financial and business data into clear, decision-ready views.

**Live demo:** https://dzimah35-eng.github.io/data-dashboard-showcase

> **Note:** All data in this project is **simulated** for demonstration. It is not real client, bank or survey data.

## Dashboards

### 1. Project cost control
Based on the kind of reporting I build for a construction company.
- Budget vs estimate at completion (EAC) for each project
- Automatic alerts for projects more than 5% over budget
- Work-in-progress (WIP) view of unbilled receivables

### 2. Credit risk thresholds
Based on my loan default modelling work.
- Expected cost across decision thresholds, using a 5:1 cost ratio for missed defaults vs wrongly rejected loans
- An interactive slider to explore the trade-off
- Illustrative chart of the top drivers of default (SHAP-style)

### 3. Financial inclusion
Based on my MSc thesis topic on financial inclusion in Ghana.
- Account ownership over time for men and women
- Ownership by group, such as location and education level

## Tools and skills shown
- Dashboard design and KPI selection
- Financial analysis (cost control, credit risk, inclusion)
- Interactive data visualisation in HTML, CSS and JavaScript

## How to view
Open the live demo link above, or download `index.html` and open it in any web browser. No setup is needed.
